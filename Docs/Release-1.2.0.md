# ScreenOff 1.2.0

Приложение больше не отображается в строке меню и Dock. Остаётся небольшое окно с одним переключателем, состоянием дисплея и кнопкой выхода.

- Откройте ScreenOff через Spotlight или из «Программ» в Finder.
- Закройте окно — выбранный режим продолжит работать в фоне. Повторное открытие вернёт то же окно без второго экземпляра приложения.
- Меню в строке меню и кнопка скрытия/показа значка полностью удалены. Свернуть окно в Dock нельзя.
- Сохранённый режим дисплея, запуск при входе, восстановление при извлечении кабеля, поведение после разблокировки и исправление ночного энергопотребления сохранены.

Пройдены 330 проверок политики и восстановления и 11 проверок нативного интерфейса, включая повторное открытие через LaunchServices и отсутствие значков в Dock и строке меню. Проверки геометрии удалённого меню больше не нужны.

Сборка для Apple Silicon, macOS 13+. Подпись ad-hoc без нотариализации Apple. Для обновления завершите старую версию кнопкой питания в окне приложения и замените ScreenOff.app в Applications файлом из DMG.
