# Security reports

Please report security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/GevorgSogomonian/ScreenOff/security/advisories/new). Include the affected version, impact and steps to reproduce. Do not post credentials or exploit details in public issues.

Ordinary display, installation or interface bugs belong in [Issues](https://github.com/GevorgSogomonian/ScreenOff/issues/new/choose).

Security fixes target the latest release. ScreenOff uses undocumented macOS display APIs; compatibility can change after a macOS update. The current release is ad-hoc signed and is not notarized by Apple. Follow the installation instructions without disabling system-wide security protections.
