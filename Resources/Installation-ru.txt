ScreenOff 1.1.0 — встроенный дисплей MacBook под вашим контролем

УСТАНОВКА
При обновлении сначала завершите старую версию кнопкой питания в её меню.
1. Перетащите ScreenOff.app в папку Applications («Программы»).
2. Запустите ScreenOff из «Программ» или через Spotlight (⌘Пробел → ScreenOff).
3. В окне один переключатель: «Использовать встроенный дисплей» с внешним монитором.
   • Включён — работают оба экрана.
   • Выключен — с внешним монитором экран MacBook автоматически отключается.
   Без внешнего монитора встроенный экран всегда включается.

Кнопка «Скрыть значок из строки меню» убирает значок, приложение продолжает
работать в фоне. Для доступа к настройкам откройте ScreenOff через Spotlight.
Кнопка «Показать значок в строке меню» возвращает значок. Закрытие окна не
завершает приложение. Режим дисплея и видимость значка сохраняются.

Выключенный переключатель также регистрирует запуск ScreenOff при входе
в macOS. Система может попросить разрешить его в «Основные → Объекты входа».
Включение переключателя включает экран и отменяет этот автозапуск.
При входе в систему окно настроек не появляется автоматически.
При обновлении прежнее включённое «Автовыключение» становится выключенным
переключателем «Использовать встроенный дисплей» — режим сохраняется.

Если Gatekeeper блокирует приложение, попробуйте запустить его, затем откройте
«Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
Сборка подписана локально (ad-hoc), без сертификата Apple Developer и нотариализации.
Отключать защиту macOS или SIP не нужно. Пароль администратора для работы не нужен.

КАК ЭТО РАБОТАЕТ
Отключение убирает встроенный дисплей из активного рабочего стола macOS.
Окна перемещаются на внешний монитор. Яркость и цвета экранов не изменяются.
При отсоединении последнего внешнего монитора встроенный экран восстанавливается.
Открытая крышка сохраняет доступ к клавиатуре, трекпаду, камере и Touch ID.
При выходе из ScreenOff экран включается. Кнопка выхода — значок питания в меню.
Выбранный режим действует и при следующих подключениях внешнего монитора.
Автовыключение работает, пока запущено приложение, включая запуск при входе.

СОВМЕСТИМОСТЬ
Эта сборка предназначена для MacBook с Apple Silicon (M1 и новее), macOS 13+.
Приложение использует закрытый API macOS: после обновлений ОС его работа может
измениться. При отсутствии API отключение блокируется с пояснением в меню.
В режиме видеоповтора сначала выключите повтор в настройках дисплеев macOS.
Окна после включения экрана могут остаться на внешнем мониторе.

ВОССТАНОВЛЕНИЕ
При отсоединении внешнего монитора приложение и отдельный процесс защиты
пытаются восстановить встроенный экран. Защита действует также при аварийном
завершении или зависании приложения. Не нужно устанавливать отдельные службы.
Попытки продолжаются при временном исчезновении дисплея, через сон и закрытие
крышки — до подтверждённого включения экрана при открытой крышке.
Если после извлечения кабеля macOS перестаёт видеть встроенный дисплей,
ScreenOff включает его по последнему подтверждённому идентификатору.
Виртуальный экран-заглушка macOS не считается внешним монитором.
После такого восстановления автоматическое отключение возобновится при
следующем подключении монитора; переключатель позволяет заново применить выбор.
Если экран не включился, откройте крышку, переподключите внешний монитор
и выполните команду в Terminal:
  /Applications/ScreenOff.app/Contents/MacOS/ScreenOff --recover
Если macOS перестала отвечать на API, выйдите из учётной записи или перезагрузите Mac.

УДАЛЕНИЕ
Включите «Использовать встроенный дисплей», завершите ScreenOff кнопкой питания
и удалите
ScreenOff.app из «Программ». Системные драйверы не устанавливаются.
